# Thread 1190421 — 做了个免费求职工具：公司官网一发职位，一分钟内通知你

- 链接：https://www.1point3acres.com/home/thread/1190421
- 发布：2026-10（1point3acres 职场版）
- 产品：JobRadar（https://www.job-radar.io/），Beta 期全免费

## 帖子要点

作者和一位做 HR 的朋友吃饭，对方说："一个岗位挂出去，头两天的简历我们基本都会看；过了一周，系统里几百份，能点开的可能就前几十个。"作者自己投了大半年，几乎所有岗位都是在 LinkedIn 上刷到的——而很多职位在官网挂出来好几天才会被同步到求职平台，"投的时候很可能已经排到没人看的那一堆里了"。

另外每家公司申请系统都不一样，手动填表重复劳动大，有次填到最后一步网页超时全没了。

于是做了 JobRadar：
- 盯着数千家主流公司官网招聘页，每周抓到 3.5 万多个新职位，一般一分钟内通知用户，"经常比求职平台早上一截"
- Chrome 插件自动填表，一份申请省十几分钟
- 拿简历和 JD 做匹配度分析，告诉用户怎么改更容易过 ATS

## 与 GTM 文档的关联

- 独立开发者"监控公司官网招聘页"赛道的又一个实例（对标 jobuzzer.com thread-1178300）
- 核心卖点"更早知道 + 1 分钟通知" = 卖 workflow 不卖数据
- 求职者端获客、免费 Beta——再次验证求职者付费意愿低、适合做流量不做主力变现
